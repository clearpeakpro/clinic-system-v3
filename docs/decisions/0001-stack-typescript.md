# 0001. Stack en TypeScript

- **Estado:** Aceptada (revisada 2026-10-24)
- **Fecha:** 2026-10-24

## Contexto

v3 se reconstruye desde cero con Claude Code y diseños de Google Stitch.

## Decisión

Se mantienen React + Vite + TypeScript, Tailwind + shadcn/ui, NestJS + Fastify, PostgreSQL + Drizzle, pg-boss, Socket.IO, pnpm + Turborepo y AWS CDK. No se cambian tecnologías por preferencia. Better Auth queda condicionado a la prueba técnica (ADR 0021).

## Consecuencias

Cualquier cambio de tecnología requiere un ADR nuevo con una razón técnica medible.
