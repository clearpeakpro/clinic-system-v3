# 0015. Terminología y tono unificados

- **Estado:** Aceptada
- **Fecha:** 2026-10-22

## Contexto

El manual documenta inconsistencias (Caja/Checkout/Cobro, tú/usted, colores de estados).

## Decisión

«Caja» en todas partes; «usted»; una sola paleta de estados con icono + texto + color; dinero en formato regional.
